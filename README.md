# 부모용 금융 교육 플랫폼 (Parent-PoPoWorld)

## 📱 프로젝트 소개
자녀의 금융 교육을 모니터링하고 관리할 수 있는 부모용 대시보드 플랫폼입니다. 자녀의 학습 현황, 투자 성과, 감정 상태 등을 실시간으로 확인하고 관리할 수 있습니다.

## 🛠 기술 스택
- **Framework**: React + TypeScript
- **상태 관리**: Zustand
- **API 통신**: Axios
- **데이터 시각화**: Recharts
- **스타일링**: CSS-in-JS
- **빌드 도구**: Vite

## 📊 주요 기능

### 1. 분석 센터 (Analysis Center)
- 자녀의 학습 진도 추적
- 투자 패턴 분석
- 감정 상태 트렌드 분석
- 데이터 시각화 대시보드

### 2. 투자 관리
- 자녀의 투자 포트폴리오 모니터링
- 수익률 추적
- 투자 성향 분석
- 리스크 관리

### 3. 퀘스트 관리
- 퀘스트 진행 상황 확인
- 새로운 퀘스트 생성
- 보상 설정 및 관리
- 학습 목표 설정

### 4. 저축 관리
- 저축 목표 설정 및 관리
- 용돈 관리
- 지출 패턴 분석
- 재무 목표 설정
